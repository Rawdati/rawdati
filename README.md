# روضتي

تطبيق ويب مستقل لإدارة الروضات، مبني بـ React + Supabase.

## النشر (Deploy)

1. ارفع هذا المشروع إلى مستودع GitHub جديد.
2. في Vercel، اضغط "New Project" واستورد المستودع.
3. أضف متغيرات البيئة التالية في إعدادات المشروع على Vercel:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. اضغط Deploy.
